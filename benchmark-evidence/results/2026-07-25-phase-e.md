## Local TCP lifecycle smoke

Two `fucina` processes were run on the same GB10 with
`FUCINA_QWEN35_WCACHE=0`, `--ctx 4096`, and `--gpu-mem-util 0.45`:

```bash
# worker
./fucina -m "$MODEL" --ctx 4096 --gpu-mem-util 0.45 \
  --dist-listen 127.0.0.1:19091 --dist-layers 16:32 --dist-final

# coordinator
./fucina -m "$MODEL" --ctx 4096 --gpu-mem-util 0.45 \
  --dist-layers 0:16 --dist-workers 127.0.0.1:19091 \
  -p 'The capital of France is' -n 2 --temp 0 --spec=false
```

Observed:

```text
Phase-E hop 0 127.0.0.1:19091 layers [16,32) final=true ready
distributed token-sequential prefill 5 tokens in 0.32s (15.5 tok/s)
The capital of France is Paris.
distributed generated 2 tokens in 0.06s (30.8 tok/s)
```

This validates real TCP handshake/ping, coordinator embedding/local range,
worker final range/head, logits return, and ACKed reset on loopback. It is not a
network performance measurement: both processes shared one GPU and both loaded
the complete model.
